# USP v0.1.0

USP turns one Markdown draft into platform-specific social posts for X, LinkedIn, Reddit, Telegram, Aegea, Bluesky, Mastodon, and Discord.

It preserves image order, so images can attach to the exact tweet, LinkedIn post, Telegram message, or Reddit body section they belong to.

![CLI dry run screenshot](./screenshot.png)

The first version supports API publishing, dry runs, custom prompts, local config, CI-friendly env vars, and JSON publish results.
